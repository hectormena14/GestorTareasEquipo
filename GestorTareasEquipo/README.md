# GestorTareasEquipo
 
Gestor de tareas en Java desarrollado de forma colaborativa con GitHub y Eclipse.
 
## Ejecución
 
1. Clonar el repositorio (Eclipse: File > Import > Git > Projects from Git > Clone URI).
2. Importar el proyecto Java y comprobar que compila.
3. Ejecutar GestorTareas (Run As > Java Application).
 
## Funcionalidades
 
- Alta de tareas (agregarTarea)
- Listado de tareas (listarTareas)
- Eliminar tarea por indice (eliminarTarea)
- Buscar tareas por texto (buscarTareas)
 
## Reparto de tareas
 
- Alumno A: alta de tareas y eliminar tarea.
- Alumno B: listado de tareas, buscar tareas y README.
- Conflicto del mensaje principal resuelto en la rama feature/mensaje-b.
 
Nota: la práctica se ha realizado de forma individual simulando los roles Alumno A y
Alumno B; el rol está indicado en el mensaje de cada commit.
